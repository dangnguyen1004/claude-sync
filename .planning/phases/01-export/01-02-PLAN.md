    - `export async function scanExportTargets(claudeDir, { include, exclude } = {})`:
      1. Call `resolveScope({ include, exclude })` to get active type list
      2. For each type in the list:
         - Look up `DATA_TYPE_MAP[type]`
         - Construct `fullPath = path.join(claudeDir, entry.subpath)`
         - If `kind === 'file'`: check `fs.access(fullPath)`, if exists: stat it, hash it, push ScannedFile. If not exists: skip silently.
         - If `kind === 'directory'`: check if dir exists with `fs.access()`. If exists: `fs.readdir(fullPath, { recursive: true, withFileTypes: true })`, filter to `isFile()`, for each file: construct absPath with `path.join(entry.parentPath, entry.name)` (Node 20+ Dirent.parentPath), check `isExcluded(absPath)` — skip if true. Hash, stat, push ScannedFile with `relativePath = path.relative(claudeDir, absPath)`.
         - If not exists: skip silently (no error, no output)
      3. Return the ScannedFile array

    - IMPORTANT: `relativePath` must NEVER start with `/`. Use `path.relative(claudeDir, absPath)` which produces paths like `skills/test-skill.md`.
    - IMPORTANT: Use streaming `hashFile()` — no `readFileSync` anywhere in this module (EXP-13).
