    **Implementation (`src/packer.mjs`):**
    - `import * as tar from 'tar';`
    - `import fs from 'node:fs/promises';`
    - `import path from 'node:path';`
    - `import os from 'node:os';`
    - `import { ALWAYS_EXCLUDED_NAMES } from './exclusions.mjs';`

    - `export function buildManifest(scannedFiles, includedTypes)`:
      Returns object matching the Manifest typedef:
      ```javascript
      {
        version: '0.1.0',
        tool: 'claude-sync',
        exported_at: new Date().toISOString(),
        source_platform: process.platform,
        included_types: includedTypes,
        files: scannedFiles.map(f => ({
          path: f.relativePath,
          size: f.size,
          checksum: f.checksum,
        })),
        excluded: {
          oauth_file: '~/.claude.json (always excluded — contains OAuth tokens)',
          runtime_dirs: Array.from(ALWAYS_EXCLUDED_NAMES),
        },
      }
      ```

    - `export async function createArchive(scannedFiles, outputPath, manifest, claudeDir)`:
      Uses the staging directory approach from research:
      1. Create temp staging dir: `fs.mkdtemp(path.join(os.tmpdir(), 'claude-sync-stage-'))`
      2. Write `manifest.json` to `path.join(stageDir, 'manifest.json')`
      3. For each scannedFile: create parent dirs in stageDir, then `fs.copyFile(f.absPath, path.join(stageDir, f.relativePath))`
      4. Create archive: `tar.create({ gzip: true, file: outputPath + '.tmp', cwd: stageDir, portable: true }, ['.'])`
      5. Atomic rename: `fs.rename(outputPath + '.tmp', outputPath)`
      6. In `finally` block: `fs.rm(stageDir, { recursive: true, force: true })`
      7. Also in `finally`: attempt `fs.rm(outputPath + '.tmp', { force: true })` to clean up partial on error

    - IMPORTANT: Use `portable: true` in tar.create options (strips uid/gid per research pitfall 5)
    - IMPORTANT: The staging approach means `cwd: stageDir` and the file list is `['.']` — tar walks the staging dir. This guarantees relative paths (SEC-02).
    - IMPORTANT: No `readFileSync` anywhere (EXP-13). The `fs.copyFile` in staging is fine — it's a kernel-level copy, not reading into JS memory.
