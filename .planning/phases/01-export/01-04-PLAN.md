       - Helper `generateDefaultOutput()`: returns `path.join(process.cwd(), 'claude-sync-' + new Date().toISOString().slice(0, 10) + '.tar.gz')`

       - `export async function runExport(outputArg, options)`:
         1. Determine output path: `outputArg ? expandTilde(path.resolve(outputArg)) : generateDefaultOutput()`
         2. Parse include/exclude from options: `options.include?.split(',').map(s => s.trim())` and same for exclude. Pass to resolveScope to validate.
         3. Get `claudeDir = path.join(os.homedir(), '.claude')`
         4. Check if `claudeDir` exists (fs.access). If not, print error `chalk.red('Claude Code directory not found: ~/.claude/')` and `process.exitCode = 1; return;`
         5. Print `console.log('Exporting Claude Code environment...\n');`
         6. Call `const files = await scanExportTargets(claudeDir, { include: parsedInclude, exclude: parsedExclude });`
         7. Group files by type: `const byType = Object.groupBy(files, f => f.type)` (Node 21+; if not available, use reduce)
         8. Print per-type summary using the CONTEXT.md output format:
            - For each type in DEFAULT_TYPES order: if type has files, print `chalk.green('  ✓ ') + typeName.padEnd(14) + chalk.dim('(' + count + ' files)')` for directories, or `chalk.green('  ✓ ') + typeName.padEnd(14) + chalk.dim('(found)')` for single files
            - If type was excluded by scope or has no files and was in scope, print `chalk.dim('  — ') + typeName.padEnd(14) + chalk.dim('(not found)')` for missing, or `chalk.dim('  — ') + typeName.padEnd(14) + chalk.dim('(skipped)')` for excluded
            - If conversations scope was active, show it; otherwise show `chalk.dim('  — projects/') + chalk.dim('      (skipped — use --include conversations to export)')`
         9. Print OAuth exclusion notice: `console.log('\n  ' + chalk.yellow('⚠') + '  ~/.claude.json excluded (contains OAuth tokens)');`
         10. Get active types from resolveScope again (or save from step 2)
         11. Call `const manifest = buildManifest(files, activeTypes);`
         12. Call `await createArchive(files, outputPath, manifest, claudeDir);`
         13. Get archive stats: `const stat = await fs.stat(outputPath);`
         14. Format size: if < 1024 bytes show bytes, if < 1MB show KB, else show MB
         15. Print final line: `console.log('\nArchive: ' + chalk.bold(path.relative(process.cwd(), outputPath)) + chalk.dim(' (' + formattedSize + ', ' + files.length + ' files)'));`

    2. Update `bin/claude-sync.mjs`:
       - Replace the placeholder export command with the real one
       - Add `import { runExport } from '../src/commands/export.mjs';`
       - Add `import chalk from 'chalk';`
       - Wire the export command:
         ```javascript
         program
           .command('export')
           .description('Export Claude Code environment to a portable archive')
           .argument('[output]', 'Output file path (default: ./claude-sync-YYYY-MM-DD.tar.gz)')
           .option('--include <types>', 'Comma-separated data types to include (overrides defaults)')
           .option('--exclude <types>', 'Comma-separated data types to exclude from defaults')
           .action(async (output, options) => {
             try {
               await runExport(output, options);
             } catch (err) {
               console.error(chalk.red('Export failed: ' + err.message));
               process.exitCode = 1;
             }
           });
         ```
       - Keep `await program.parseAsync(process.argv);` at the end
