<task type="auto">
  <name>Task 3: Create src/restorer.mjs — core import pipeline with conflict detection</name>
  <files>src/restorer.mjs, src/restorer.test.mjs</files>
  <action>
    Create src/restorer.mjs exporting runRestore(archivePath, options):

    Options: { claudeDir?, force?, dryRun? }

    Pipeline:
      1. Determine targetDir = options.claudeDir ?? path.join(os.homedir(), '.claude')
      2. Create stagingDir = await fs.mkdtemp(path.join(os.tmpdir(), 'claude-sync-import-'))
      3. Extract archive to stagingDir: tar.extract({ file: archivePath, cwd: stagingDir })
         - SEC-03: tar npm v7.5.11+ patches CVE-2026-31802; additionally validate entry paths with path.resolve() check inside onReadEntry: reject any entry where path.resolve(stagingDir, entry.path) does not start with stagingDir
      4. Read manifest = JSON.parse(await fs.readFile(path.join(stagingDir, 'manifest.json'), 'utf-8'))
      5. For each file in manifest.files (in order):
         - destPath = path.join(targetDir, file.path)
         - Check exists: await fs.access(destPath).then(() => true).catch(() => false)
         - If dryRun: print file path with CONFLICT/OVERWRITE/NEW label, continue
         - If exists AND NOT force: return { conflict: true, file: file.path, existingContent: await fs.readFile(destPath, 'utf-8') }
           (do NOT prompt here — prompts belong in the command layer)
         - If exists AND force: (backup handled in command layer)
         - Ensure parent dir: await fs.mkdir(path.dirname(destPath), { recursive: true })
         - await fs.copyFile(path.join(stagingDir, file.path), destPath)
      6. Clean up stagingDir in finally block
      7. Return { success: true, restoredCount, conflictCount }

    For --dry-run output format (per file):
      - NEW: chalk.green('  + ') + path + chalk.dim(' (new)')
      - CONFLICT: chalk.yellow('  ! ') + path + chalk.dim(' (conflict — would overwrite)')
      - For dryRun mode, collect all results into a summary object

    Note: Per-file backup (IMP-05) and path rewriting (IMP-04) are handled by the command layer (import.mjs) that calls restorer. restorer itself does NOT prompt, backup, or rewrite — it exposes conflict and relies on the caller for those concerns.
  </action>
  <verify>
    <automated>npm test -- --run src/restorer.test.mjs 2>&1 | tail -30</automated>
  </verify>
  <done>runRestore extracts files, detects conflicts, supports dryRun mode, returns structured result</done>
